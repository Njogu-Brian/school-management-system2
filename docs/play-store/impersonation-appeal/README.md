# Google Play impersonation appeal — Royal Kings Admin

Google removed or blocked the **Royal Kings Admin** store listing because it uses the school’s name, logo, and “official staff app” wording without a **signed** permission document.

Emails, WhatsApp messages, and screenshots **will be rejected**. Google only accepts:

- an agreement signed by both parties, or
- a signed authorization / declaration letter, or
- a signed licensing / distribution agreement

**Print these Word files** (logo box + yellow fill-in lines already laid out):

- `01-Authorization-Letter.docx`
- `02-Brand-Licence-Agreement.docx`

Open in Word → insert the school crest in the dashed box → type the Director’s name over the yellow lines → print → sign in blue ink → stamp → scan both to colour PDF → upload with the appeal.

## What Google flagged

| Location | Evidence |
|---|---|
| Full description (en-GB) | Claims this is the official staff app for Royal Kings School |
| App name (en-GB) | Royal Kings Admin |
| Short description (en-GB) | Staff ERP for Royal Kings School |
| App icon (en-GB) | School crest / logo |
| Feature graphic (en-GB) | “Royal Kings Admin — Staff ERP for Royal Kings School” |

Package: `com.royalkingsschools.admin`  
Play Console developer account shown: **Royal Kings Admin**  
Policy: [Impersonation](https://support.google.com/googleplay/android-developer/answer/9888379)

## What you must do (in this order)

1. Open `01-Authorization-Letter.docx` and `02-Brand-Licence-Agreement.docx` in Microsoft Word.
2. Click the dashed logo box → Insert → Pictures → pick the school crest (the circular mark, not the purple square Play icon if you can crop it).
3. Type over every **yellow** line: Director’s name, title, ID, publisher name, address, Play Console email, signing date.
4. Delete the red instruction line at the top.
5. Print both. Print the licence twice if each party should keep an original.
6. Sign in blue ink. Stamp the school stamp in the dashed stamp box. Publisher signs the second block.
7. Scan each signed document to a colour PDF (300 dpi). Do not crop letterhead, signatures, or stamps.
8. Optionally update the store listing with the copy in `04-store-listing-copy.md`.
9. In Play Console, open the impersonation issue → **Submit an appeal** → paste `03-play-console-appeal.md` → attach the two signed PDFs.

Do **not** wait for a reply by email. The appeal is submitted only inside Play Console.

## Who must sign

**School / rights holder (Party A)**  
Royal Kings Premier School LTD (trading as Royal Kings School), Wangige, Kiambu County, Kenya.

Must be someone with authority to license the school name and logo: director, proprietor, principal, or company secretary. Google will compare the name, title, and school details with the public website.

**Developer / publisher (Party B)**  
The person or company that owns the Google Play Console account that published `com.royalkingsschools.admin`.

If the Play Console account is a personal account, Party B is that individual. If it is a company, Party B is that company and a director signs.

## What not to send

- Emails, chat screenshots, or “please approve this” messages
- Unsigned Word/Google Docs
- Photos of the school gate or logo with no signature
- A letter signed only by the developer
- A letter that does not name the package `com.royalkingsschools.admin`

## After Google accepts

The previous version can stay live while the new listing is restored. If they ask for more proof, send the same signed PDFs again plus a colour photo of the signed originals next to a school ID card (still keep the signed letter as the main proof).
